# App policies

Site GitHub Pages commun pour les politiques de confidentialité de Mirovolt et Kezak Mood.
HTML et CSS statiques : aucun outil d’analyse, dépendance, build ou formulaire.

- Accueil : https://rafal83.github.io/app-policies/
- Mirovolt : https://rafal83.github.io/app-policies/mirovolt/
- Kezak Mood : https://rafal83.github.io/app-policies/kezak-mood/

Chaque politique propose des sections françaises et anglaises (`#fr`, `#en`).
Le contenu Kezak Mood reprend la politique existante, datée du 6 janvier 2026.
La politique Mirovolt décrit la version actuelle ; revoir son contenu lors de
changements du traitement des données et mettre à jour sa date.

Pages publie la racine de la branche `main`. Une modification poussée sur cette
branche met à jour le site. Le dépôt ne contient que les textes et styles publics,
sans code applicatif ni identifiants de publication.
